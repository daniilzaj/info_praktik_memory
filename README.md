# Исследование иерархии памяти

Программа на C для процессора i5-12450H. Она получает N и модель CPU через стандартный ввод. Скрипт `run.sh` извлекает модель из `/proc/cpuinfo` на текущей Linux-машине и передает ее программе. При другой модели программа сообщает `Wrong CPU model`.

```bash
git clone https://github.com/daniilzaj/info_praktik_memory.git
cd info_praktik_memory
gcc main.c -o main
./run.sh
```

Для N=100000 на машине i5-12450H ожидается:

```text
CPU from /proc/cpuinfo: i5-12450H
N: 100000
Sum: 5000050000
Code: 0359073825
```

Для демонстрации буферизации нужен `strace`. При отсутствии команды в CachyOS: `sudo pacman -S strace`. Затем:

```bash
./demo_buffering.sh
```

Скрипт считает системные вызовы `read(0, ...)` при чтении тех же входных данных с отключенной и обычной буферизацией. В обычном терминале Enter может требоваться в обоих режимах, потому что это поведение терминала, а не буфера `stdin`.

Для отчета нужны скриншоты вывода `./run.sh` и `./demo_buffering.sh`.
