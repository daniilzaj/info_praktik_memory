# Исследование иерархии памяти

Программа на C для CPU i5-12450H. Входные данные: число N на первой строке и модель CPU на второй.

```bash
gcc main.c -o main
./main < input.txt
```

Для N=100000 и модели i5-12450H ожидается:

```text
Sum: 5000050000
Code: 0359073825
```

Сделайте скриншот терминала, на котором видны команды сборки, запуска и вывод.
